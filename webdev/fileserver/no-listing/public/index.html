Directory listings are disabled on this server

/docs/ returns 404 Not Found — the listing is hidden because docs/ has no index.html.

But /docs/secret.txt is still served if you already know the file name: hiding is not the same as protecting. Real protection means checking who is asking (authorization), not whether they know where things are.

/about/ works normally: directories that DO contain an index.html are unaffected by the wrapper.
