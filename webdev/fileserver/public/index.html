It works! You are being served by Go.

This page is public/index.html, served by http.FileServer(http.Dir("./public")). Nothing here is "generated" — the exact bytes on disk are the exact bytes on the wire.

URLs to try while reading main.go

  • /docs/ — a directory with no index.html → auto-generated listing
  • /docs (no trailing slash) — the server redirects it (301) to /docs/
  • /index.html — also redirected: URLs ending in index.html collapse to ./
  • /notes.txt — plain text (text/plain)
  • /data.json — JSON (application/json)
  • /pixel.png — a binary file (image/png)
  • /static/notes.txt — same tree, mounted under /static/ via http.StripPrefix
  • /hello/reader — a normal Go handler, not a file (pattern with a wildcard)
  • /download — public/notes.txt with Content-Disposition: attachment (forces a "save as" dialog)
  • /files/notes.txt — one file chosen by URL, with input validation
  • /missing.txt — does not exist → 404 page not found

Open your browser's devtools (network tab) and reload: you will see each of the requests above as a separate HTTP transaction, each with its own Content-Type header.
