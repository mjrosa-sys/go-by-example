This page lives inside the compiled binary

The file you are reading was compiled into the executable at build time by a //go:embed assets directive. There is no assets directory on the server that this program needs at run time — build the binary, delete this folder, and the program still serves everything.

  • / — this index.html (root of the embedded FS)
  • /docs/ — directory listing works over embed.FS too

Try it: go build -o app . && ls -lh app — notice the assets are part of the binary's size now.
